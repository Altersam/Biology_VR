**Образовательная VR-игра / production documentation**

## GitHub Pages

Для публикации сайта:

1. загрузить содержимое этой папки в корень репозитория;
2. открыть **Settings → Pages**;
3. выбрать **Deploy from a branch**;
4. выбрать ветку `main` и папку `/ (root)`;
5. сохранить.

Главная страница сайта — `index.html`.

Сайт полностью статический и не требует сборки, Node.js или внешних библиотек.

## Главный принцип документации

Каждая сцена содержит прямые ссылки на все пресеты, которые в ней используются.  
Каждый пресет содержит обратные ссылки на сцены, в которых он участвует.

Это позволяет использовать репозиторий как **production bible** для Unity/Blender, а не только как презентацию идеи.

## Технологическая логика

- Unity — игровая сборка.
- Blender — создание 3D-моделей.
- XR-взаимодействие — руки, захват, сканер и BioTool.
- Пресеты проектируются как переиспользуемые Prefab/State-модели.
- Внутри артерии игрок находится в просвете сосуда, а не наблюдает его снаружи.
- Свободная локомоция не является основной механикой.
