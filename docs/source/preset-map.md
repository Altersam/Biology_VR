# BIOLOGY VR — карта использования пресетов по сценарию

## Техническое ТЗ для Unity / Blender

**Основа:** текущий сценарий `Cценарий.md`  
**Формат:** VR, Unity  
**Принцип:** один визуальный пресет = один самостоятельный ассет/набор состояний, который может переиспользоваться в нескольких сценах.  
**Ключевое ограничение:** игрок не ходит свободно по уровню. В лаборатории он находится в одной рабочей зоне. В артерии игрок всегда находится **внутри просвета сосуда**, а события подаются в зоне перед игроком.

---

# 1. Общая техническая логика пресетов

Пресеты делятся на четыре группы.

| Группа | Что входит | Как загружается |
|---|---|---|
| Постоянные интерфейсные | информационный экран, HUD, профессор, руки игрока | существуют почти всю игру |
| Постоянные инструменты | сканер, BioTool | появляются в лаборатории, затем вызываются игроком в артерии |
| Базовая среда | лаборатория, артерия, поток крови, плазма | основа соответствующей локации |
| Сценарные биологические объекты | клетки, молекулы, патологии, вирусы, тромб, повреждения | создаются и удаляются по событиям конкретной сцены |

### Постоянно активные элементы в артерии

Начиная со Сцены 3 и до завершения Сцены 16 в сцене постоянно доступны:

- Артерия — основной тоннель.
- Поток крови.
- Плазма крови.
- Фоновые эритроциты.
- HUD жизненных показателей.
- Информационный экран.
- Профессор-голограмма.
- Руки игрока.
- Ручной сканер.
- BioTool.

Некоторые сцены меняют параметры этих же пресетов, а не создают новые.

Например:

- Сцена 5 меняет скорость кровотока и радиус артерии.
- Сцена 10 меняет состояние давления и тонус стенки.
- Сцена 16 возвращает поток и пульсацию к нормальному состоянию.

# 2. СЦЕНА 1. ЛАБОРАТОРИЯ

**Время:** 0:00–5:00  
**Назначение:** обучение базовым действиям и постановка миссии.

## Используемые пресеты

| Пресет | Роль в сцене | Взаимодействие | Состояние |
|---|---|---|---|
| Стартовая биологическая лаборатория | основное окружение | нет свободного перемещения | активна всю сцену |
| Профессор-гид | обучение и реплики | реагирует на этапы обучения | физическая фигурка / голограмма по центру |
| Лабораторный стол | рабочая зона | размещение предметов | постоянный |
| Информационный экран | инструкции, термины, формулы | вкладки и обновление контента | обучение |
| HUD жизненных показателей | показывает исходные параметры | пассивный | ЧСС 72, АД 120/80, SpO₂ 98 %, 36,6 °C |
| Ручной сканер | первое обучение исследованию | взять, навести, удержать | лежит на док-станции |
| BioTool | знакомство с основным игровым инструментом | взять в руку | базовый режим, остальные режимы заблокированы |
| Камера уменьшения | подготовка перехода | активируется в конце сцены | ожидание → активация |
| Эритроцит | первый учебный биологический объект | захват, вращение, масштабирование, сканирование | обычный → увеличенный учебный |
| Гемоглобин | вложенный объект исследования | отделить от учебного эритроцита, сканировать | учебная увеличенная модель |
| Гемовая группа | углублённый уровень гемоглобина | рассмотреть, выделить | часть гемоглобина |
| Атом железа Fe | углублённый уровень гемовой группы | выделение/подсветка | связан с гемом |
| Кислород O₂ | молекулярный интерактив | снять с учебной модели и вернуть | свободный → связанный |
| Углекислый газ CO₂ | сравнение с O₂ | взять, просканировать | отдельная учебная молекула |

## Техническая последовательность

```text
Лаборатория активна
→ обучение захвату
→ эритроцит
→ сканер
→ увеличение эритроцита
→ гемоглобин
→ гемовая группа / Fe
→ O₂
→ CO₂
→ BioTool
→ исходные показатели HUD
→ постановка миссии
→ активация камеры уменьшения
```

## Что не требуется создавать отдельно

Голографическая модель организма и кровеносной системы может быть UI/голографическим контентом информационного экрана и не обязана существовать как отдельный полноценный игровой пресет.

# 3. СЦЕНА 2. УМЕНЬШЕНИЕ

**Тип:** переходный эпизод.  
**Новой игровой механики нет.**

## Используемые пресеты

| Пресет | Использование |
|---|---|
| Лаборатория | исходная среда перехода |
| Камера уменьшения | главный физический объект перехода |
| Профессор | остаётся видимым в начале, затем визуально удаляется |
| Информационный экран | отображает изменение масштаба |
| HUD | временно приглушается, затем возвращается |
| Артерия | плавно проявляется в конце перехода |
| Эритроциты | начинают появляться при входе в микромир |
| Поток крови | включается в финальной фазе перехода |

## Эффекты

```text
голубое поле
→ световые кольца камеры
→ изменение визуального масштаба лаборатории
→ пространственное искажение
→ усиление сердцебиения
→ голубой свет → красный
→ проявление внутренней стенки артерии
→ появление эритроцитов
→ запуск кровотока
```

**Важно:** переход выполняется без телепортационного затемнения.

# 4. СЦЕНА 3. АРТЕРИЯ — ЗНАКОМСТВО С КРОВЬЮ

**Время:** 6:00–10:00

## Базовые пресеты среды

| Пресет | Роль |
|---|---|
| Артерия — основной тоннель | основное окружение |
| Поток крови | движение объектов через сцену |
| Плазма крови | визуальная жидкая среда |
| Эритроциты | основной массовый объект потока |
| HUD | нормальные показатели |
| Информационный экран | задания и карточки объектов |
| Профессор-голограмма | подсказки |
| Сканер | основное средство исследования |
| BioTool | присутствует, но активные боевые режимы ещё закрыты |

## Интерактивные пресеты

### Эритроцит

Используется как повторение механики из лаборатории.

Состояния:

```text
движение в потоке
→ замедление около игрока
→ захват рукой
→ сканирование
→ увеличение
→ учебный разрез
```

Связанные пресеты:

- гемоглобин;
- гемовая группа;
- Fe;
- O₂;
- CO₂.

### Лейкоцит

Используется как отдельный объект поиска в потоке.

Действия:

- найти;
- взять;
- просканировать;
- добавить в журнал.

### Тромбоцит

Используется в двух состояниях:

- неактивированный;
- активированный.

В Сцене 3 игрок только изучает оба состояния. Реальная активация используется позднее в гемостазе.

### Плазма крови

Используется как фон и как учебный объект.

Дополнительные пресеты, которые можно показывать в расширенном режиме:

- белки плазмы;
- ионы плазмы.

## Используемые пресеты

| Пресет | Использование |
|---|---|
| Артерия — основной тоннель | основная среда |
| Эндотелий | первый выделяемый слой стенки |
| Слои стенки артерии | интерактивный послойный режим |

Пресет «Слои стенки артерии» должен позволять включать по отдельности:

1. эндотелий;
2. внутреннюю оболочку;
3. среднюю оболочку;
4. наружную оболочку.

Игрок находится **внутри сосуда**. Никакой внешний вид целого сосуда как основной игровой ракурс не используется.

# 7. СЦЕНА 6. АТЕРОСКЛЕРОТИЧЕСКАЯ БЛЯШКА

**Время:** 14:00–17:00  
**Основная механика:** точный BioTool-шутер.

## Главные пресеты

| Пресет | Роль |
|---|---|
| Атеросклеротическая бляшка | главный объект сцены |
| Липидное ядро | внутренняя часть бляшки |
| Фиброзная покрышка | защищаемая поверхность |
| Пенистая клетка | компонент бляшки |
| Макрофаг | образовательная демонстрация происхождения пенистых клеток |
| Частица LDL | представитель липопротеинов |
| Артерия | среда |
| Поток крови | показывает нарушение потока вокруг бляшки |
| BioTool | режим «Импульс» |
| Сканер | первичное исследование |

## Сборка объекта

```text
стенка артерии
+ липидное ядро
+ пенистые клетки
+ воспалительная зона
+ фиброзная покрышка
= атеросклеротическая бляшка
```

### Частица LDL

Используется как учебная визуализация в схеме:

```text
липопротеины
→ накопление липидов
→ воспаление
→ макрофаг
→ пенистая клетка
→ бляшка
```

Не обязана массово присутствовать в игровом потоке.

## Ошибочное воздействие

При попадании BioTool в фиброзную покрышку используется пресет:

### Повреждённая / разорванная бляшка

После разрыва дополнительно активируются:

- тромбоциты;
- фибрин;
- формирование тромба.

При критическом результате загружается контрольная точка перед бляшкой.

| Антиген / вирусный шип | отдельная выделяемая часть |

## Структура вирусной частицы

В одном префабе должны быть выделяемые компоненты:

- генетический материал;
- капсид;
- поверхностные структуры;
- антиген;
- эпитоп.

### Антиген / вирусный шип

Используется как отдельный пресет учебного увеличения.

Он должен иметь:

- полный вид;
- выделяемый эпитоп;
- состояние «связан с антителом».

В конце сцены вирусная частица снова включается в поток и уходит дальше.

## Используемые пресеты

В этой сцене **не создаются новые биологические объекты**.

Используются только уже известные:

- артерия;
- поток крови;
- эритроциты;
- BioTool;
- HUD;
- информационный экран;

## Изменения состояния существующих пресетов

### HUD

```text
АД
118/76
→ 108/70
→ 98/64
→ 92/60
```

### Артерия

BioTool открывает режим «Сосудистое поле».

Игрок может:

- слегка сузить участок;

Визуально становится менее стабильным и менее интенсивным.

| Повреждённая внутренняя стенка сосуда | расширенное состояние повреждённого участка |

## Предпочтительная сборка

Пресет повреждения не является «целым сосудом снаружи».

```text

→ локальный разрыв эндотелия
→ обнажённый субэндотелиальный матрикс
→ выход крови
```

Игрок всегда смотрит на повреждение **из просвета артерии**.

# 13. СЦЕНА 12. ГЕМОСТАЗ

**Время:** 26:30–30:00  
**Механика:** управление клетками + puzzle.

## Используемые пресеты

| Пресет | Использование |
|---|---|
| Локальный разрыв эндотелия | место гемостаза |
| Тромбоцит | основной управляемый клеточный объект |
| Тромбоцитарная пробка | результат агрегации |
| Фибрин | отдельные нити / материал сети |
| Фибриновая сеть | финальная пространственная структура |
| Стабильный тромб | итоговый объект сцены |
| Фибриноген | образовательный молекулярный уровень |
| Тромбин | образовательный молекулярный уровень |
| BioTool | режим «Управление» |
| HUD | давление |
| Информационный экран | термины и последовательность |

## Фаза 1. Адгезия

Используются:

- тромбоцит в спокойном состоянии;
- локальный разрыв;
- обнажённый матрикс.

Состояние тромбоцита:

```text
покой
→ контакт с повреждением
→ прикрепление
```

## Фаза 2. Активация

Пресет тромбоцита переключается:

```text
дисковидная форма
→ отростки
→ активированная форма
```

## Фаза 3. Агрегация

Несколько тромбоцитов объединяются.

Создаётся составной пресет:

### Тромбоцитарная пробка

Она должна быть отдельным техническим состоянием, чтобы управлять:

- размером;
- количеством тромбоцитов;
- степенью закрытия дефекта.

## Фаза 4. Фибрин

Основной игровой уровень:

```text
первые нити фибрина
→ разветвление
→ фибриновая сеть
→ стабилизация пробки
```

### Фибриноген и тромбин

В базовом прохождении могут быть показаны только на информационном экране / в увеличенной учебной вставке.

В старшем режиме:

```text
фибриноген
+ действие тромбина
→ фибрин
→ фибриновая сеть
```

# 14. СЦЕНА 13. БАЛАНС ГЕМОСТАЗА

## Используемые пресеты

Повторно используются:

- локальный разрыв эндотелия;
- тромбоциты;
- тромбоцитарная пробка;
- фибриновая сеть;
- стабильный тромб;
- поток крови;
- эритроциты;
- HUD;
- BioTool;
- информационный экран.

## Три состояния

### Недостаточный гемостаз

- небольшая пробка;
- слабая фибриновая сеть;
- продолжающийся выход крови;
- давление продолжает снижаться.

### Оптимальный гемостаз

- дефект закрыт;
- тромб закреплён у стенки;
- просвет сосуда остаётся открытым;
- кровоток сохранён.

### Избыточный гемостаз

Используется тот же пресет стабильного тромба, но его масштаб/объём увеличивается.

Результат:

- просвет сужается;
- скорость потока меняется;
- HUD показывает ухудшение кровотока.

**Отдельный новый «гигантский тромб» не требуется.**

# 16. СЦЕНА 15. ФИНАЛЬНЫЙ ВИРУСНЫЙ ОЧАГ

**Время:** 31:30–36:00

## Базовая сборка босса

«Финальный вирусный очаг» — это **композитный игровой пресет**, а не один гигантский вирус.

Он собирается из:

- инфицированной клетки;
- множества малых вирусных частиц;
- визуальной зоны заражения;
- точек выхода новых вирусных частиц.

## Фаза 1. Сдержать распространение

Используются:

- финальный вирусный очаг;
- инфицированная клетка;
- малые вирусные частицы;
- BioTool в режиме иммунного управления;
- HUD вирусной нагрузки.

Логика:

```text
инфицированная клетка
→ постоянно создаёт вирусные частицы
→ частицы летят в рабочую зону
→ игрок перехватывает их
```

## Фаза 2. Найти антиген

Используются:

- малая вирусная частица;
- антиген / вирусный шип;
- сканер;
- информационный экран.

Антиген должен позволять отдельно подсветить:

- весь вирусный шип;
- эпитоп.

## Фаза 3. Антитела

Используются:

- антитело;
- антиген / эпитоп;
- малая вирусная частица;
- нейтрализованный вирусный комплекс.

Перед игроком появляются несколько вариантов антител.

После правильного выбора:

```text
антитело
→ связывание с эпитопом
→ вирусная частица с антителами
→ нейтрализованный вирусный комплекс
```

## Фаза 4. Фагоциты

Используются:

- нейтрализованный вирусный комплекс;
- макрофаг;
- при необходимости нейтрофил;
- BioTool.

Игрок направляет клетки к связанным вирусным частицам.

Вирусная нагрузка:

```text
100 % → 72 % → 48 %
```

## Фаза 5. Инфицированная клетка

Используются:

- инфицированная клетка;
- цитотоксический Т-лимфоцит;
- сканер;
- BioTool.

Последовательность:

```text
сканирование источника
→ обнаружение инфицированной клетки
→ появление Т-лимфоцита
→ направление к клетке
→ контакт
→ распознавание
→ контролируемая гибель инфицированной клетки
```

**Взрыва клетки быть не должно.**

## Фаза 6. Финальная очистка

Используются:

- остаточные малые вирусные частицы;
- антитела;
- нейтрализованные вирусные комплексы;
- макрофаги;
- клеточный детрит;
- HUD.

После уничтожения инфицированной клетки генерация новых вирусов прекращается.

### B-лимфоцит / плазматическая клетка

Этот пресет **не обязателен для основной механики текущего сценария**.

Лучшее использование:

- образовательная вставка при объяснении происхождения антител;
- свободный режим исследования;
- расширенный старший уровень.

Не нужно вводить его как ещё одну обязательную фазу босса.

# 21. КАКИЕ ПРЕСЕТЫ ЯВЛЯЮТСЯ СОСТАВНЫМИ

Эти элементы лучше не делать как полностью независимые уникальные биологические модели. Их следует собирать из уже существующих ассетов.

## Тромбоцитарная пробка

```text
несколько активированных тромбоцитов
+ точка фиксации к повреждению
= тромбоцитарная пробка
```

## Стабильный тромб

```text
тромбоцитарная пробка
+ фибриновая сеть
+ захваченные эритроциты
= стабильный тромб
```

## Финальный вирусный очаг

```text
инфицированная клетка
+ генераторы малых вирусных частиц
+ визуальная зона заражения
= финальный вирусный очаг
```

## Нейтрализованный вирусный комплекс

```text
малая вирусная частица
+ несколько антител
= нейтрализованный вирусный комплекс
```

## Восстановленная стенка

Лучше реализовать не отдельным новым тоннелем, а финальным состоянием модульного пресета стенки:

```text
повреждённый эндотелий
→ очищенный участок
→ восстанавливающийся эндотелий
→ восстановленная стенка
```

## Главный production-принцип

Если объект отличается только состоянием, **не создавать новый независимый пресет без необходимости**.

Предпочтительно:

```text
один базовый префаб
+
несколько Mesh / Material / Animation State
+
управление состояниями из Unity
```

Примеры:

- один тромбоцит → покой / активация / адгезия;
- один эндотелий → здоровый / повреждённый / восстановление;
- один вирус → обычный / помеченный / нейтрализованный;
- один поток крови → нормальный / замедленный / нарушенный;
- одна артерия → нормальная / суженная / расширенная.

Это позволит сохранить единый визуальный стиль и не размножать почти одинаковые модели.
