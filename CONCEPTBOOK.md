# BIOLOGY VR — CONCEPTBOOK

## Версия 1.0

**Формат:** образовательная VR-игра  
**Движок:** Unity  
**Создание 3D-ассетов:** Blender  
**Продолжительность основной миссии:** ориентировочно 30–40 минут  
**Структура:** лаборатория → переход в микромир → единая извилистая артерия → восстановление гомеостаза → возвращение → финальный отчёт

---

# 1. Коротко об игре

**Biology VR** — образовательная игра, в которой игрок становится исследователем микромира и проходит единую миссию внутри кровеносной системы.

Главный принцип проекта:

> **Сначала наблюдаем. Потом делаем вывод.**

Игра не строится как виртуальная экскурсия по организму. Игрок последовательно сталкивается с биологическими процессами, исследует их руками и приборами, получает терминологию только после наблюдения, а затем применяет изученное в механике.

Основная цепочка:

```text
наблюдение
→ взаимодействие
→ сканирование
→ термин / модель / формула
→ игровое применение
→ физиологический результат
```

Финальная цель — не «победить врага», а **восстановить гомеостаз организма**.

# 2. Игровой мир

В первой версии используются две физические локации.

## 2.1. Стартовая лаборатория

Статичная футуристическая биологическая лаборатория.

Игрок находится в одной рабочей позиции и не перемещается по комнате.

Перед игроком находятся:

- профессор-гид;
- центральный лабораторный стол;
- ручной сканер;
- BioTool;
- главный информационный экран;
- HUD жизненных показателей;
- камера уменьшения;
- учебные биологические объекты.

Назначение лаборатории:

- обучение VR-взаимодействиям;
- знакомство с инструментами;
- первый молекулярный эксперимент;
- фиксация исходных показателей;
- постановка миссии;
- финализация после возвращения.

## 2.2. Артерия

Основная игровая локация — **игрок находится внутри просвета артерии**.

Артерия представляет собой слегка извилистый органический тоннель. Она используется как единое пространство почти для всей основной миссии.

Внутри постоянно присутствуют:

- внутренняя поверхность сосуда;
- эндотелий;
- поток крови;
- плазма;
- эритроциты;
- редкие лейкоциты;
- тромбоциты;
- информационный интерфейс;
- HUD;
- профессор в виде небольшой голограммы;
- вызываемые игроком сканер и BioTool.

Игрок не бегает по сосуду. Между сюжетными эпизодами его игровая позиция плавно переносится вдоль артерии. Все ключевые взаимодействия происходят перед ним в зоне досягаемости.

# 3. Визуальное направление

## 3.1. Общий стиль

**Стилизованный научный реализм.**

Цель — избежать двух крайностей:

- медицинского хоррора;
- слишком детской мультяшности.

Объекты должны быть:

- биологически узнаваемыми;
- визуально выразительными;
- хорошо читаемыми в VR;
- достаточно крупными для обучения;
- пригодными для захвата, вращения, масштабирования и сканирования.

## 3.2. Цветовая система

Лаборатория:
- холодный сине-голубой технологический свет;
- тёплые оранжевые акценты оборудования;
- белые/металлические поверхности.

Микромир:
- красно-розовая органическая среда артерии;
- эритроциты — насыщенно-красные;
- иммунные клетки — холодные голубые/фиолетовые;
- тромбоциты — фиолетовые;
- вирусные объекты — контрастные фиолетово-красные;
- учебные и интерактивные подсветки — голубые;
- опасные состояния — красные/оранжевые.

# 4. Грамматика взаимодействия

Вся игра строится на небольшом наборе повторяемых действий.

## Руки

Игрок может:

- брать объект;
- отпускать;
- передавать между руками;
- вращать;
- приближать;
- масштабировать учебную модель двумя руками;
- отделять учебные компоненты;
- соединять элементы;
- нажимать физические кнопки.

## Сканер

Принцип:

```text
навести
→ удерживать
→ сканирование
→ визуальное выделение
→ термин / описание на информационном экране
```

Используется для:

- клеток;
- молекул;
- стенки сосуда;
- патологических участков;
- вирусных структур;
- инфицированных клеток.

## BioTool

Основной активный инструмент.

Режимы открываются постепенно:

1. **Базовый режим** — знакомство с прибором.
2. **Импульс** — точное воздействие.
3. **Притяжение** — дистанционный захват и перемещение.
4. **Управление** — направление клеток и биологических объектов.
5. **Сосудистое поле** — временное изменение тонуса участка сосуда.
6. **Иммунное управление** — работа с вирусными и иммунными объектами.

# 5. Постоянные интерфейсы

## Информационный экран

Один и тот же пресет используется всю игру.

Содержимое меняется по ситуации:

- обучение;
- текущее задание;
- подсказки;
- термин;
- описание объекта;
- 3D-визуализация;
- формула;
- измерения;
- предупреждение;
- вывод;
- итоговый отчёт.

Экран не должен постоянно занимать центр поля зрения. Он разворачивается при необходимости.

## HUD жизненных показателей

Постоянно находится справа сверху.

Основные параметры:

| Параметр | Исходное значение |
|---|---:|
| ЧСС | 72 уд/мин |
| Артериальное давление | 120/80 мм рт. ст. |
| SpO₂ | 98 % |
| Температура | 36,6 °C |

HUD становится частью механики: температура растёт во время вирусной волны, давление падает при кровопотере, показатели возвращаются к норме после восстановления.

# 6. Научная модель

Игра использует реальные понятия, но часть визуализации намеренно масштабируется.

Ключевой принцип:

> Условное увеличение допустимо, если интерфейс явно сообщает, что размер учебной модели не соответствует реальному масштабу.

Примеры формул и схем:

### Связывание кислорода

\[
Hb + O_2 \rightleftharpoons HbO_2
\]

### Расход потока

\[
Q = vS
\]

### Упрощённая модель Пуазейля

\[
Q=\frac{\pi \Delta P r^4}{8\eta L}
\]

В игре формула Пуазейля используется как **идеализированная учебная модель**, а не как точное описание всей гемодинамики живого сосуда.

### Антиген — антитело

\[
Ag + Ab \rightleftharpoons AgAb
\]

# 8. Финальный вирусный очаг

Финальный босс принципиально **не является одним огромным вирусом**.

Техническая сборка:

```text
инфицированная клетка
+
генераторы малых вирусных частиц
+
визуальная зона заражения
=
финальный вирусный очаг
```

Игровая логика строится на последовательном использовании уже изученных понятий:

```text
вирусная частица
→ антиген / эпитоп
→ антитело
→ нейтрализованный комплекс
→ фагоцитоз
→ поиск источника
→ цитотоксический T-лимфоцит
→ прекращение продукции вируса
→ очистка
```

Это превращает финал не в обычную стрельбу, а в итоговую проверку понимания иммунного ответа.

# 9. Гемостаз как центральная puzzle-механика

Гемостаз представлен не одной кнопкой, а последовательным процессом:

```text
повреждение эндотелия
→ адгезия тромбоцитов
→ активация
→ агрегация
→ первичная тромбоцитарная пробка
→ фибриноген
→ тромбин
→ фибрин
→ фибриновая сеть
→ стабильный тромб
```

После формирования тромба появляется задача **баланса**.

Игрок должен одновременно выполнить два условия:

```text
КРОВОТЕЧЕНИЕ ОСТАНОВЛЕНО
+
КРОВОТОК СОХРАНЁН
```

# 10. Образовательные уровни

Материал проекта можно использовать по-разному в зависимости от класса.

## 7 класс

Подходят:
- базовое знакомство с микромиром;
- клетка;
- мембрана;
- органоиды;
- вирус как неклеточная форма;
- отличие клетки организма от микроорганизма.

В текущей основной миссии это скорее ознакомительный режим с упрощёнными текстами.

## 8 класс

Подходят:
- транспорт веществ;
- кровеносные системы;
- сосуды;
- движение веществ;
- газообмен;
- диффузия;
- осмос.

Можно включать физические параметры, но без сложной молекулярной детализации.

## 9 класс

Это основной уровень для текущей версии игры.

Прямо используются:
- кровь;
- плазма;
- эритроциты;
- лейкоциты;
- тромбоциты;
- свёртывание крови;
- иммунитет;
- кровообращение;
- давление и пульс;
- гомеостаз.

Углублённый уровень позволяет раскрыть:
- гемоглобин;
- транспорт газов;
- гемостаз;
- иммунологию;
- строение сосудов.

## 10 класс

Наиболее академичный режим.

Подходят:
- химический состав клетки;
- мембранный транспорт;
- фагоцитоз;
- вирусы;
- клеточный гомеостаз;
- транспорт веществ;
- антиген;
- антитело;
- клеточный и гуморальный иммунитет.

Именно для 10 класса можно максимально раскрыть молекулярные модели, формулы и финальный иммунный эпизод.

## 11 класс

Текущая миссия напрямую покрывает программу слабее.

Возможные расширения:
- эволюция патогенов;
- естественный отбор;
- изменчивость;
- паразитизм;
- взаимодействие «хозяин — патоген».

Это лучше оформлять как отдельное дополнение, а не искусственно встраивать в основную миссию.

# 11. Принцип построения пресетов

Основное правило production:

> **Если объект отличается только состоянием, не делать новый независимый ассет без необходимости.**

Примеры:

### Тромбоцит
```text
покой
→ активация
→ адгезия
→ агрегация
→ элемент пробки
```

### Эндотелий
```text
здоровый
→ повреждённый
→ разрыв
→ очищенный
→ восстанавливающийся
→ восстановленный
```

### Вирус
```text
обычный
→ исследуемый
→ помеченный
→ связанный антителами
→ нейтрализованный
→ удаляемый
```

### Поток крови
```text
нормальный
→ учебно замедленный
→ нарушенный около препятствия
→ ослабленный при падении давления
→ кровопотеря
→ нормализованный
```

# 15. Главная идея проекта

В первой версии не требуется пытаться показать весь организм.

Сильная сторона проекта — **единая артерия как последовательная образовательная среда**, в которой один объект приводит к следующему:

```text
кровь
→ строение сосуда
→ гемодинамика
→ патология
→ вирус
→ кровопотеря
→ гемостаз
→ иммунный ответ
→ восстановление
→ гомеостаз
```

Игрок не просто читает определения. Он получает понятие после того, как увидел процесс и взаимодействовал с ним.

Это и должно оставаться главным критерием при добавлении новых механик.
