Conceptbook

Единое видение Biology VR: игровой мир, научные принципы, взаимодействия, интерфейсы, сцены, образовательные уровни и production-архитектура.

Markdown-версияПолный сценарий
Идея

Не экскурсия по организму, а научная миссия

Игрок последовательно наблюдает биологическое явление, взаимодействует с ним, сканирует, получает термин и затем использует знание в следующем действии. Финальная цель — восстановить гомеостаз, а не просто уничтожить противника.

Сначала наблюдаем. Потом делаем вывод.

Лаборатория

Одна фиксированная рабочая позиция. Профессор, стол, сканер, BioTool, информационный экран, HUD и камера уменьшения.

Артерия

Единый извилистый тоннель. Игрок находится внутри просвета сосуда, а события последовательно появляются перед ним.

Возврат

После восстановления гомеостаза тот же переход работает в обратную сторону, а финальный отчёт снова проходит в стартовой лаборатории.

Interaction grammar

Пять повторяемых действий

Руки

Захват, вращение, передача, масштабирование, отделение и соединение учебных компонентов.

Сканер

Навести → удержать → визуальное выделение → термин и описание на постоянном информационном экране.

BioTool

Импульс, притяжение, управление, сосудистое поле и иммунное управление открываются по мере прохождения.

Scientific layer

Учебная модель

Учебные объекты могут быть увеличены относительно реального масштаба, но интерфейс должен явно маркировать условность размера. Формулы появляются в старшем режиме только там, где они помогают объяснить наблюдаемую механику.

СвязьИспользование
Hb + O₂ ⇄ HbO₂Учебное связывание кислорода с гемом.
Q = vSСвязь расхода, скорости и площади сечения.
Q = πΔPr⁴/(8ηL)Идеализированная модель для старшего режима.
Ag + Ab ⇄ AgAbСпецифическое связывание антигена и антитела.

Production-принцип

Состояния одного биологического объекта должны максимально переиспользовать один Prefab.

Base Prefab
├─ Mesh / LOD
├─ Materials
├─ Collider
├─ ScannerTarget
├─ XR Interaction
├─ State Controller
├─ Animator / BlendShapes
├─ VFX hooks
└─ Scene events

Например, один тромбоцит имеет состояния покоя, активации, адгезии и агрегации; один эндотелий — здоровое, повреждённое и восстановленное состояния.
